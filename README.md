## Search indexing

Every HTML page includes a robots meta directive: `noindex, nofollow, noarchive, noimageindex`. Crawling is allowed so search engines can read the directive; a robots.txt crawl block would prevent that. On this project site, robots.txt would only apply from the domain root, not the repository subpath.

These directives request exclusion from cooperating search engines, following [Google’s guidance](https://developers.google.com/search/docs/crawling-indexing/robots-meta-tag). They do not make the site or public repository private; existing search results may take time to disappear after recrawling.
